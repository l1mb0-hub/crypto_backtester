# crypto_backtester

Бэктестер стратегий на тиковых данных Binance spot (aggTrades: каждая агрегированная сделка с ценой, объёмом и стороной агрессора).

## Данные

- **По умолчанию** дневные архивы с [data.binance.vision](https://data.binance.vision): один zip на сутки UTC, проверка SHA256, кэш в `data_cache/` (pickle). Файл за день появляется на следующие сутки, поэтому по умолчанию последний день — вчера.
- **`--api-hours N`** — последние N часов через REST `/api/v3/aggTrades` (по 1000 сделок за запрос, без кэша). Подходит для свежих данных, для суток и больше удобнее архивы.
- **`--synthetic`** — сгенерированные тики, если нет доступа к Binance.

Время в дампах с 2025 года в микросекундах, в API в миллисекундах: единица определяется автоматически.

Объём: BTCUSDT — порядка 1–3 млн тиков в сутки, около 0.5–1 ГБ памяти на сутки при бэктесте.

## Модель исполнения

- Сигнал на тике исполняется на первом тике после `t + latency` (`--latency-ms`, по умолчанию 50).
- `--exec quote` (по умолчанию): bid/ask восстанавливаются из сделок (покупка агрессора идёт по ask, продажа по bid), спред сглаживается медианой. Позиция оценивается по mid, на каждое изменение позиции платится полуспред.
- `--exec trade`: исполнение и оценка по цене следующей сделки, спред не платится. Для частых сделок результат завышен.
- Комиссия `--fee-bps` и дополнительное проскальзывание `--slippage-bps` списываются с каждого изменения позиции.
- Train/test делятся по времени (70/30).

## Стратегии

Окна задаются временем (`"30s"`, `"5min"`), а не числом свечей.

- `mean_reversion` — z-score цены относительно скользящего среднего, выход при |z| < 0.5.
- `momentum` — пересечение скользящих средних с полосой `band_bps`, чтобы позиция не дребезжала около нуля.
- `flow_imbalance` — дисбаланс объёма агрессивных покупок и продаж за окно (на свечах этого признака нет).

## Метрики

Доходность, годовой Sharpe (по минутной доходности equity), max drawdown, число сделок, комиссии, оплаченный спред, проскальзывание, время в позиции (по времени, а не по числу тиков).

## Запуск

```
pip install -r requirements.txt
python main.py                              # BTCUSDT, вчерашние сутки
python main.py --symbol ETHUSDT --days 3
python main.py --end-date 2026-11-10 --days 2
python main.py --api-hours 2
python main.py --fee-bps 2 --latency-ms 200 --slippage-bps 0.5
python main.py --exec trade
python main.py --optimize
python main.py --synthetic
```

`--optimize` перебирает параметры mean reversion на train и выводит Sharpe лучших трёх на test.

## Структура

- `data.py` загрузка тиков
- `strategies.py` стратегии
- `backtest.py` оценка bid/ask, бэктест и метрики
- `main.py` запуск
